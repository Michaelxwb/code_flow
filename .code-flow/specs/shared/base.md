# Project Base

## Rules

- [RULE-001] 所有行为变更包含有意义的测试，覆盖成功、错误和重要真实边界。
  ✅ 用临时项目和真实子进程验证状态、协议与失败恢复。
  ❌ 只断言实现源码中存在某个字符串。

- [RULE-002] 每个函数只承担一个明确职责，函数体不超过 50 行。
  ✅ 将命令解析、校验、执行和渲染拆成独立函数。
  ❌ 在一个函数中实现整套 CLI 生命周期。

- [RULE-003] 外部 JSON、参数和持久文件必须明确校验类型与合法取值。
  ✅ 只有 literal true 表示开启；整数必须是正的安全整数。
  ❌ 把 "true" 或 "2" 静默当成布尔值或数字。

- [RULE-004] 错误必须显式处理，Hook stdout 只输出协议 JSON，诊断写 stderr。
  ✅ 输入错误降级且退出 0；写入冲突返回明确错误码。
  ❌ 吞掉异常后写 done，或把日志写入 Hook stdout。
